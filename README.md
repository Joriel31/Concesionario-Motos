# Concesionario de Motos Kawasaki

Proyecto web desarrollado para la materia de desarrollo web. Presenta una vitrina virtual de motocicletas Kawasaki con especificaciones, galería de fotos y formulario de contacto.

## Tecnologías Utilizadas
* HTML5 (Estructura semántica)
* CSS3 (Estilos y diseño responsive)
* Git y GitHub (Control de versiones y flujo de trabajo con ramas)

## Estructura de Ramas
* `main`: Rama principal de producción.
* `desarrollo`: Rama donde se integran las funcionalidades antes del despliegue.
* `feature-galeria`: Rama de característica para la construcción de la galería de imágenes.
